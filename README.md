# 🌾 CropClaim Local

Privacy-conscious, local-first smallholder crop-insurance claim evidence and workflow support.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app.py
```

Administrative decision support only; it does not determine coverage, validity, compensation, eligibility, fraud, or liability.
